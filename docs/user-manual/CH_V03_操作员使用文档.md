# CH_V03 测试系统操作员使用文档

适用范围：CH_V03 测试系统桌面端、设备通讯、MES、插件导出、客户方案、测试项和运行数据页面。  
文档日期：2026-07-09  
面向人员：产线操作员、班组长、工程师、管理员。

> 说明：本目录 `images` 下已有界面图，可用于 Word/PDF 版本排版。当前截图为界面示意图；如果需要完全等同现场程序的真实截图，可以运行程序后重新截图替换同名图片。

## 1. 系统用途

CH_V03 用于产线测试工站。系统完成扫码、下位机通讯、测试流程控制、测试项显示、MES 卡关和上传、结果文件导出、良率统计、运行日志记录等工作。

典型生产流程如下：

1. 操作员登录系统。
2. 确认客户、产品、测试类型、测试程式、站位、工单等信息。
3. 连接扫码枪和下位机。
4. 扫描产品条码，系统按配置做条码校验。
5. 在线模式下，系统向 MES 做测试前卡关。
6. 下位机开始测试并返回测试项目结果。
7. 系统判定 PASS/FAIL，刷新良率和失败项。
8. 系统按配置导出 CSV、DCL、CsvMes 或客户插件文件。
9. 在线模式下，系统向 MES 上传测试结果。

## 2. 登录界面

![登录界面](images/01-login.png)

### 2.1 账号

输入登录账号。系统默认内置以下账号：

| 账号 | 默认密码 | 角色 | 说明 |
| --- | --- | --- | --- |
| operator | 123456 | 操作员 | 用于日常生产，主要查看和运行。 |
| engineer | 123 | 工程师 | 可维护系统、通讯、MES、插件等配置。 |
| admin | admin | 管理员 | 拥有用户、客户方案导入、管理员工具等完整权限。 |

### 2.2 密码

输入账号对应密码。密码区分配置中保存的内容，修改后以用户配置页面为准。

### 2.3 登录按钮

校验账号和密码，通过后进入主界面。登录后底部状态栏会显示当前用户显示名称和角色。

### 2.4 取消按钮

退出登录流程并关闭窗口。

## 5. 通讯设置

![通讯设置](images/04-communication.png)

路径：配置管理 > 设备通讯 > 扫码枪 / 下位机通讯

扫码枪和下位机都支持四种通讯方式：

| 通讯方式 | 作用 |
| --- | --- |
| SerialPort | 串口通讯，需要配置 COM 口和波特率。 |
| TcpClient | 本系统作为客户端连接设备，需要配置设备 IP 和端口。 |
| TcpServer | 本系统作为服务端等待设备连接，需要配置监听 IP 和端口。 |
| Disabled | 禁用该设备，不建立连接。 |

### 5.1 扫码枪配置

| 配置项/按钮 | 作用 |
| --- | --- |
| 通讯方式 | 选择扫码枪连接方式。 |
| 串口号 | 串口通讯时使用的 COM 口。 |
| 波特率 | 串口通讯速率。 |
| IP 地址 | TCP 通讯时使用的 IP。 |
| 端口 | TCP 通讯时使用的端口。 |
| 超时(ms) | 连接或通讯超时时间，单位毫秒。 |
| 自动扫码触发 | 开启后系统会向扫码枪发送触发命令。 |
| 扫码触发命令 | 触发扫码枪扫码的命令，支持 `\r`、`\n` 转义。 |
| 扫码停止命令 | 停止扫码枪扫码的命令，支持 `\r`、`\n` 转义。 |
| 测试扫码枪连接 | 按当前配置尝试连接扫码枪，并显示测试结果。 |

### 5.2 下位机配置

| 配置项/按钮 | 作用 |
| --- | --- |
| 通讯方式 | 选择下位机连接方式。 |
| 串口号 | 串口通讯时使用的 COM 口。 |
| 波特率 | 串口通讯速率。 |
| IP 地址 | TCP 通讯时使用的 IP。 |
| 端口 | TCP 通讯时使用的端口。 |
| 超时(ms) | 连接或通讯超时时间，单位毫秒。 |
| 连接后请求测试项 | 连接下位机成功后，系统主动发送请求测试项命令。 |
| 请求测试项命令 | 请求下位机返回测试项目列表的命令，默认 `Itemnum\r\n`。 |
| 条码验证成功后同时发送默认 OK 命令 | 条码校验通过后，根据条码内容向下位机发送 OK 命令。 |
| 条码内容到成功命令映射 | 条码内容到命令的映射，例如 `L=DMOK1\r\n;B=DMOK2\r\n`。 |
| 测试下位机连接 | 按当前配置尝试连接下位机，并显示测试结果。 |

### 5.3 保存和退出

| 按钮 | 作用 |
| --- | --- |
| 保存 | 保存通讯配置。 |
| 退出 | 放弃修改。 |

## 14. 日常生产操作步骤

### 14.1 开班检查

1. 登录系统。
2. 查看主界面标题，确认客户、产品、测试类型、测试程式正确。
3. 查看站位和工单，确认与现场工单一致。
4. 查看扫码枪、下位机、MES 状态灯。
5. 若状态为红色，点击对应状态灯连接设备。
6. 需要 MES 在线生产时，点击 MES 状态灯切换为在线。
7. 检查测试项目表是否有项目、上下限是否正确。
8. 必要时点击“清空良率”开始新批次统计。

### 14.2 正常测试

1. 放置产品或治具。
2. 扫描产品条码。
3. 系统显示 SN。
4. 在线模式下系统执行 MES 卡关。
5. 下位机返回测试结果。
6. 查看测试状态 PASS/FAIL。
7. FAIL 时查看 FAIL 项、测试项目表红色行和运行日志。
8. 按现场规则处理产品。

### 14.3 换线或换工单

1. 使用管理员账号导入对应客户方案，或由工程师修改基础/MES/通讯配置。
2. 确认工单、站位、治具、测试类型、测试程式。
3. 保存配置。
4. 重新连接设备。
5. 清空良率。
6. 用首件或模拟数据确认导出和 MES 上传。

## 15. 常见异常处理

| 现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 扫码枪未连接 | COM 口错误、设备被占用、TCP 地址错误、扫码枪未上电。 | 检查通讯配置和设备连接，点击状态灯或测试连接。 |
| 下位机未连接 | 串口/网络配置错误、下位机未启动、防火墙拦截。 | 检查通讯方式、COM、波特率、IP、端口和防火墙。 |
| 扫码后无反应 | 条码长度或前缀不符合规则，扫码枪未触发，下位机未收到 OK 命令。 | 检查基础配置中的条码规则和通讯配置中的触发/OK 命令。 |
| MES 无法在线 | MES 未启用、插件未选择、URL 错误、账号密码错误、网络不通。 | 检查 MES 配置、插件配置，使用 MES 调试工具测试。 |
| MES 卡关失败 | 条码不允许过站、工单/站位/治具错误、前站未完成。 | 按 MES 返回信息处理，核对工单、站位、治具和条码。 |
| 测试项为空 | 未配置测试项，或下位机未返回测试项。 | 检查测试项配置和“连接后请求测试项”命令。 |
| 结果导出失败 | 路径不存在或无权限，插件参数错误。 | 检查保存路径、客户导出插件配置和磁盘权限。 |
| 良率不正确 | 未清空上一批统计，或模拟测试计入统计。 | 换线或开班前点击“清空良率”。 |
| 连续 NG 报警 | 连续失败达到阈值。 | 停线检查治具、线材、下位机、产品状态和测试程序。 |
